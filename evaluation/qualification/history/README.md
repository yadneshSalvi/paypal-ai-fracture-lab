# Pre-study qualification history

These records precede the 600 scheduled model candidates. They contain local control executions, capability probes, provider API binding checks and software checks. They are not additional quality attempts and do not count as live payment evidence.

Full final control receipts are retained under the timestamped `controls-*` directory. Final safety and anonymous-process qualifications are also retained. `development-logs/manifest.json` identifies the available earlier development logs by content hash. Earlier raw control/probe JSON files were overwritten while the harness was being developed; the retained summary logs are the available history for those runs. No missing detailed receipt has been reconstructed or presented as observed evidence.

The main current qualifications point to the unchanged, frozen runtime. Historical failures and older image identities remain historical and must not be mistaken for results on that runtime.
