# Geist fonts

The unmodified Latin Geist and Geist Mono WOFF2 assets were copied from the pinned Next.js 16.4.6 dependency's `dist/next-devtools/server/font/` directory. They are loaded locally with `next/font/local` and do not require a build-time font download.
