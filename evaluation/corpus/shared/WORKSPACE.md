# Candidate workspace contract

Repair only `candidate.ts` (TypeScript) or `candidate.py` (Python). Export `handle(context, command)` with the supplied signature. Every invocation may run in a **new process**. Concurrent invocations share the durable store and provider account for this case, but do not share globals. The caller may retry the same business command with a different transport attempt ID. Your return is a JSON object with `status` and `httpStatus`; the task describes additional result fields.

The context's `client` is the actual pinned APIMatic SDK: TypeScript `paypal`2.29.0 or Python `paypal`2.29. The provider is an offline deterministic fixture, not real funds. It enforces one capture per order, explicit completed/pending/refused states, finite refundable balances, and endpoint `PayPal-Request-Id` deduplication. It does not make your application idempotent. Generic `Idempotency-Key` is observed but is not the modeled provider identity. Its supported endpoints are create/get/capture Orders and get capture/refund/get refund Payments. No search by request ID exists. Provider writes require an owning intent; all identifiers in the task store are fictional.

`store` is persistent SQL owned by the target. `get(table,key)` returns a JSON record with `version`, or null/None. `list(table)` returns `{key,value}` records. `insert` commits a unique table/key and raises a coded error `SQLITE_CONSTRAINT_UNIQUE` if it already exists. `patch` merges fields; optional expectedVersion/expected_version performs compare-and-swap and raises `VERSION_CONFLICT` on a stale version. `remove` deletes only that target row. Database errors have `.code`. An error must not be recognized from its message. No method takes arbitrary SQL. Table/key lengths and total calls are bounded.

`reserve(key,resource,amountMinor,limitMinor,metadata)` atomically inserts a unique row in `reservations` and refuses with `CAPACITY_EXCEEDED` if the sum of other rows for this resource whose state is `held`, `unknown`, `pending` or `completed` plus this amount exceeds the supplied limit. The row stores `resource`, `amountMinor`, `state:'held'` and metadata. It raises the same duplicate-key error for an existing key. The caller chooses a correct scoped key, current limit, metadata and state transitions; the store cannot infer those business decisions. Reserve is a capacity transaction, not a provider payment or a payment-identity helper. External refunds already reflected in a resource must be accounted for exactly once.

`requestId(...parts)` / `request_id(*parts)` deterministically derives a UUID from the supplied string tuple. It does not decide which fields constitute the business operation. `verify(event)` checks the exact delivered envelope against the configured fixture's signature record and returns a boolean. It makes no state change. No signature flag inside the event is trusted.

Imports may use the supplied `api` types, `paypal` public exports, and ordinary standard-library data/crypto helpers. Python `httpx2` imports are restricted to exception types. Do not create clients, replace transports, change SDK dependencies, inspect process/environment/filesystem, execute subprocesses, use networking, or change protected source/tests. Do not disable typing or catch and discard unexpected programming errors. TypeScript computed property access uses only literal string or numeric keys; use ordinary typed properties, `Map` methods, or array iteration for dynamic data. Reflection, dynamic imports and Python private/dunder attributes are forbidden. Code that attempts these actions fails the source policy. The sandbox independently denies external access; the source policy is additional protection.

The model has a bounded read-only file tool and may request the original baseline's public compile/test result. It cannot run an edited draft before its one final submission. Hidden cases and golden controls are not in this workspace. All outcomes are graded by executed invariants after that first submission; prose claims do not affect the result. Keep any concise explanation outside the source. Never include private reasoning.
